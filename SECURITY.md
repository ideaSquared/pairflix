# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request.

Use GitHub's private vulnerability reporting:
<https://github.com/ideaSquared/pairflix/security/advisories/new>

Include what you found, where, and the steps to reproduce it, so we can confirm it quickly.

## What to expect

- We acknowledge a report within 3 working days.
- We confirm whether it is a vulnerability and share a plan or timeline within 10 working days.
- We keep you updated until it is fixed, and credit you in the advisory if you want that.

## Scope

Pairflix is pre-launch alpha. Report issues in this repository's code and configuration
(the API Worker in `services/api`, the web apps in `apps/`, and the workflows in `.github/`).
